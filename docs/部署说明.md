# 部署说明（银掌柜 · 银行 AI 智能体）

本文件对应提交材料「03 源代码与部署材料」。按以下步骤可在**任意一台未装过依赖的电脑**上跑起来。

---

## 一、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11、macOS、Linux 均可 |
| Python | 3.10 及以上（开发验证于 3.14） |
| 内存 | ≥ 512 MB（纯内存账本，无数据库） |
| 网络 | **离线可运行**；只有拉取依赖时需要网络 |
| 端口 | 默认 8000（可改） |

---

## 二、三步启动

```bash
# 1) 进入目录
cd yinzhanggui-agent

# 2) 安装依赖（只有 fastapi / uvicorn / pytest / httpx）
pip install -r requirements.txt

# 3) 启动
python run.py 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即成功。

**Windows 用户也可以直接双击** `启动演示.bat`：自动启动服务并打开浏览器。

> 若所在环境禁止 pip 清理临时目录（受限沙箱、离线内网机，报错 `Permission denied: *.whl.metadata`），
> 改用自带引导脚本：`python tools/getdeps.py`，依赖会解包到 `.pylibs/`，`run.py` 会自动加载，无需设置环境变量。

## 五、目录结构

```
app/           后端（FastAPI）：意图理解、任务规划、权限引擎、执行器、安全模块、账本、渠道
web/           前端（原生 JS，无需构建）：落地页、登录、注册、个人中心、控制台
tests/         120 个自动化测试
docs/          技术文档、安全自评报告、答辩 PPT、配图与生成脚本、录屏脚本
tools/         依赖引导脚本、演示剧本重放、前端一致性检查
run.py         启动入口（自动加载 .pylibs）
启动演示.bat    Windows 一键启动
```

## 六、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `Address already in use` | 8000 被占用 | 换端口：`python run.py 8001` |
| 页面样式错乱 | 浏览器缓存旧 CSS/JS | Ctrl+F5 硬刷新 |
| `ModuleNotFoundError: fastapi` | 依赖未安装 | `pip install -r requirements.txt` 或 `python tools/getdeps.py` |
| 侧栏看不到「一键演示」 | 默认折叠（面向客户界面隐藏） | 点侧栏最下方「演示工具 ▾」展开 |
| 想恢复初始数据 | 演示中被改乱 | 演示工具 →「重置演示数据」 |

## 七、可选：接入真实大模型

系统默认使用**本地确定性理解器**，不联网也能完整运行。若要启用 LLM 增强（仅影响意图识别，不影响权限判定）：

```bash
export YINZHANGGUI_LLM_BASE_URL=https://api.deepseek.com/v1
export YINZHANGGUI_LLM_API_KEY=sk-xxxx
export YINZHANGGUI_LLM_MODEL=deepseek-chat
```

未配置或调用失败时，系统自动降级为规则引擎，功能不中断。
